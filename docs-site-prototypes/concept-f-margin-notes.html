Everyday control

Keep the Thread in your hands.

Slash commands are deterministic product operations. They never hide a model prompt or start an Agent turn.

A useful distinction: natural language asks the Agent to reason; slash commands operate the product directly.
/modelChoose a provider and modelsetup
/permissionsReview or change the Thread's active modesafety
/diffInspect controlled workspace changeschanges
/undoReverse the latest reversible ChangeSetrecovery

Permissions are Thread-scoped

Awesome begins in Request approval mode. Full access allows ordinary operations for the current Thread, while hard safety denials still run first.

A good review rhythm

Use /diff before keeping a change. Use /undo when the journal can safely reverse it; shell side effects may not be reversible.
