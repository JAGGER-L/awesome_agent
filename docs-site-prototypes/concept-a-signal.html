Docs/Quickstart
5 minute setup

Go from intent to a verified change.

Install Awesome, open it inside a project, and complete your first safe session in five focused steps.

1. Install Awesome

The release bundle includes the runtimes it needs. Choose the command for your platform, then open a new terminal.

macOS or WSL2 Ubuntu
$ curl -fsSL https://github.com/JAGGER-L/awesome_agent/releases/latest/download/install.sh | sh
Windows PowerShell
PS> irm https://github.com/JAGGER-L/awesome_agent/releases/latest/download/install.ps1 | iex
Git is optional

Awesome never installs Git automatically. Add it only when your workflow needs Git-aware operations.

2. Start inside a project

Terminal
$ cd <project>
$ awesome

The directory where you launch Awesome becomes the workspace. Awesome shows the resolved path before it loads project instructions or uses tools.

3. Complete the first session

Trust the workspaceChoose Yes only when you recognize the directory and are comfortable allowing access.
Configure a modelRun /model, choose DeepSeek or Kimi, then enter the key in the masked input.
Send a read-only first taskAsk Awesome to analyze the project structure and recommend where to start reading.
