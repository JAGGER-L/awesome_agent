The governing invariant

Python Core is the only authority for product behavior. Ink submits typed intent and renders events; it never calls models, executes graphs, runs tools, or writes product state.

Why this boundary exists

A second surface can adapt the same Application facade without recreating Thread, Turn, policy, or recovery semantics.

Ownership at a glance

Application owns lifecycleWorkspace initialization, commands, interactions, cancellation, recovery, Thread and Turn.
Agent owns the loopContext, model calls, tool routing, budgets, compression, and finalization.
Tool policy owns authorityEvery built-in and MCP tool follows the same registry, policy, and executor path.
