# Awesome Docs Site Prototypes

This folder is a disposable design exploration for the future Awesome documentation
site. It does not replace the Markdown documentation under `docs/`.

Open `index.html` through a local static server to compare three directions:

- **A — Signal:** task-first, calm, and optimized for daily documentation use.
- **B — Terminal Native:** product-led, dark, and strongly tied to the Ink TUI.
- **C — Field Guide:** editorial, architectural, and optimized for long-form reading.

The second design round keeps A's documentation structure, removes B from the
active shortlist, and adds three A/C hybrids:

- **D — Editorial Signal:** A's three-column shell with C's paper, serif, and
  vermilion visual language.
- **E — Blueprint:** A's navigation model rendered as a precise engineering
  reference system.
- **F — Margin Notes:** A's usability with a softer annotated-manual reading
  experience.

The recommended production stack and information architecture are documented in
`SITE_PLAN.md`.
