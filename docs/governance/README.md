# Governance

Governance documents describe durable project direction and maintenance rules.
They are not local execution plans.

- [Roadmap](roadmap.md)
- [Technical debt](technical-debt.md)
- [Documentation governance](documentation.md)
- [Quality](quality.md)
- [Roadmap history](archive/roadmap-history.md)

## Governance Documents

- `roadmap.md` owns product direction.
- `technical-debt.md` owns durable debt.
- `quality.md` owns quality posture and validation expectations.
- `documentation.md` owns documentation placement and update rules.

Local execution plans and handoffs belong under ignored `.codex/exec-plans/`.
